- 服务地址：`http://127.0.0.1:17800`；本地 `stx` 软连接仍指向 `dist/stx`。
- 个人资料更新：管理员语言 `zh -> en -> zh` 成功，缺少 `--confirm` 时未调用业务接口。
- 用户创建：通过 `--password-stdin` 创建普通用户，CLI stdout、stderr 和数据库执行结果均未出现密码；相同幂等键重试复用结果，修改请求正文返回冲突。
- 用户更新：昵称、邮箱、`--active=false`、`--admin=false` 和密码更新均验证成功；新密码可以登录，随后恢复为启用状态。
- 权限：普通用户调用管理员 CLI 和直接 API 均返回 403，未发生越权修改。
- 用户删除：第一次请求返回 R2 `confirmation_id`，第二次使用同一幂等键和确认编号成功删除；用户查询返回不存在，重复删除请求保持幂等。

## 风险文件

- `internal/apps/auth/handler.go` 和 `internal/apps/admin/user_handler.go`：不能泄露密码，也不能破坏网页接口。
- `internal/apps/execution/`：同步写辅助方法会被后续多个模块复用。
- `internal/cmd/root.go` 和共用写辅助文件：错误注册会影响根命令。
- `internal/operation/registry.go` 与路由基线：只接受本批 4 条路由变化。
