# 工作台响应式布局重构（顶栏 / 三栏 / 视口高度 / 窄屏抽屉）

## 背景与痛点

数据同步工作台（`/workbench`，`DataSyncStudio`）目前存在四类明显的响应式布局缺陷，在 1280×720 / 1440×900 笔记本、分屏窗口与窄屏设备下体验较差：

1. **顶栏最小宽度过高（≥1350px），中窄屏必溢出**：
   - 顶栏写死 3 列网格且中间搜索槽固定占 `280px`（收起成圆钮时仍白占空间），右侧工具栏为不可折行 `min-w-max`，同时左侧还重复展示了编辑器下方已有的完整目录面包屑；在 1280px 或分屏下右侧按钮被挤出屏幕或左侧文件名被压扁。
2. **垂直高度双层叠加冲突，必出双滚动条且矮屏裁切控制台**：
   - 外层 `ProjectLayout` 为普通滚动页留了 `py-6 pb-28 mb-8`（168px），内层工作台又写死 `h-[calc(100vh-96px)] min-h-[780px]`，叠加恒超 `100vh`；在 1080p 屏幕也会出现多余整页滚动条，在 MacBook 13/14 寸或 720p 屏幕直接将底部控制台顶出视口，空画布 `min-h-[380px]` 也会在矮屏裁切主按钮。
3. **三栏主网格缺乏容器宽度自适应**：
   - 左右侧栏（左 180–420px、右 280–560px）最多占用 `980px`，中屏同时打开两侧栏会把中间编辑区与控制台压成极窄缝隙；拖拽分隔条没有保护中间区最小宽度；窄屏（`<960px`）也不会退化为浮层抽屉。
4. **控制台与内部提示条在窄宽下拥挤**：
   - 只读提示横幅、执行中提示条、控制台分段栏与日志信息头在窄中间栏下容易溢出或折行凌乱；空日志提示卡片的 `min-h-[180px]` 在矮控制台下会被裁切。

---

## 范围

### 范围内（In Scope）

1. **工作台页面外壳高度**：`frontend/app/(main)/layout.tsx`（仅对 `/workbench` 路由启用全视口无多余滚动外壳，不影响其他控制台页面）。
2. **工作台响应式布局引擎（纯函数）**：`frontend/components/common/sync/sync-studio-utils.ts`（视口模式分档、左右宽与控制台高动态保护夹紧，不破坏用户持久化偏好）。
3. **顶栏、主网格、窄屏抽屉与内部细条**：`frontend/components/common/sync/DataSyncStudio.tsx`、`frontend/components/common/sync/studio-chrome.css`、`frontend/components/common/sync/ConsolePanel.tsx`。
4. **单元测试覆盖**：`frontend/components/common/sync/__tests__/sync-studio-utils.test.ts` 及必要的组件/契约测试（保持现有测试与 Playwright E2E 选择器全兼容）。

### 范围外（Out of Scope）

- 不改动任何后端接口或 CLI。
- 不修改其他路由（`/dashboard`、`/clusters`、`/monitoring`、`/diagnostics` 等）的外层布局。
- 不改动 `frontend/components/arc/*` vendored 源码（仅通过其公开 props 组合使用）。
- 不新增独立全屏专注模式按钮（仍保留左右侧栏独立开合，遵守既有 `#110 AC3` 约定）。

## 核心需求

### R1 · 全视口零双滚动与动态控制台高度保护

- `/workbench` 路由在常规桌面高度（≥520px）下**严禁出现页面级纵向滚动条**，工作台整体刚好铺满底部悬浮 Dock 上方的视口区域，且底部不被 Dock 遮挡。
- 控制台高度在容器变矮时按可用高度动态夹紧，确保编辑器始终保留足够的最小可视高度（≥180px），同时**不覆写**用户已保存到 `localStorage` 的理想高度（窗口恢复放大后自动还原）。
- 编辑器空态引导画布去掉过大的 `min-h-[380px]`，在矮屏下也能完整显示「新建任务」入口。

### R2 · 顶栏渐进收拢，任何桌面/平板宽度零横向溢出

- 移除收起态仍永久占用 `280px` 的静态搜索列；搜索按钮常态仅占 `36px`，点击展开时平滑向内浮层展开（不推挤任何按钮，不遮挡右侧栏开关）。
- 顶栏不再重复拼接完整父目录面包屑（编辑器标签栏下方已有完整目录面包屑），仅展示当前文件名（悬停 `title` 保留完整路径）与状态/共享入口，为顶栏释放空间。
- 顶栏随容器宽度分档渐进紧凑：
  - **宽屏（≥1200px）**：完整显示集群名、探查按钮组（测试连通/DAG/预览）、带文案主操作组（保存/发布/运行/停止 + 更多菜单）。
  - **中屏（900px–1199px）**：隐藏次要集群名（右侧设置栏可见），主操作组切换为纯图标模式（保留 Arc 原生 Tooltip 与可访问名称），探查按钮组紧凑展示，保证 1024px 充裕不溢。
  - **窄屏（<900px）**：将探查动作（测试连通/DAG/预览）收纳进主操作组末尾下拉菜单，隐藏顶栏版本与只读微胶囊（编辑区横幅与共享浮层仍保留完整信息），保证窄至 480px 也不发生横向溢出，且**左栏开关、文件名、共享按钮、搜索、核心保存/运行/菜单、右栏开关始终可达**。

### R3 · 三栏主网格三档自适应与中栏最小宽度保护

- 基于工作台主容器实际宽度（`ResizeObserver`）划分为三档：
  - **宽屏（≥1280px）**：支持左右侧栏同时常驻展开并自由拖拽；渲染与拖拽时强制保护中间编辑区最小宽度（≥420px），左右侧栏无法把编辑区挤爆；同样不破坏用户持久化偏好。
  - **中屏（960px–1279px）**：左右侧栏改为**单侧常驻互斥**（展开右侧自动暂收左侧，反之亦然），同时保护中栏 ≥420px；从宽屏缩至中屏若两侧均开，优先暂收右侧高级栏，保留左资源树与编辑区。
  - **窄屏（<960px）**：主网格退化为单栏全宽（编辑区与控制台占满 100% 宽度）；左右侧栏改为贴边浮层抽屉（带半透明遮罩，点击遮罩或按 `Esc` 关闭，窄屏下选中文件自动关闭左抽屉）；隐藏左右垂直拖拽手柄；从宽/中屏缩至窄屏时自动收起已展开侧栏避免挡住编辑区。
- 首帧 SSR 与水合必须使用与服务端一致的默认布局，挂载后再同步容器实测尺寸，严禁产生 React Hydration 警告。

### R4 · 控制台与内部提示条窄宽友好

- 编辑区只读提示横幅、顶部 `actionPending` 提示条在窄宽下平滑折行、不产生横向滚动条。
- 控制台顶栏左侧 `SegmentedControl` 在极窄宽下可横向平滑滚动，右侧高度切换/最大化图标按钮始终固定不被挤出。
- `ConsolePanel` 顶部元信息条与日志头在窄宽下允许合理折行/截断，空日志/混合日志引导卡片去掉 `min-h-[180px]` 防止矮控制台裁切。

### R5 · 兼容现有测试与 E2E 契约

- 在标准 1280×720 视口（Playwright 默认尺寸）下，工作台首屏直接可见左资源栏（含「资源操作 / Resource actions」按钮）、主编辑区、底部控制台（含「任务 / Jobs」按钮）与带文字的主操作组。
- 保留 `data-studio-left-sidebar`、`data-studio-right-sidebar`、`data-testid="studio-toggle-left-sidebar"`、`data-testid="studio-toggle-right-sidebar"` 等既有属性与 `studio-explorer-width.test.ts` 契约。

## 验收标准（Acceptance Criteria）

- [ ] **AC1（全高无双滚动）**：`/workbench` 使用独立贴合视口外壳，无 `min-h-[780px]` 与 `h-[calc(100vh-96px)]` 冲突；控制台高度在矮容器下动态夹紧且保护编辑器最小高度（≥180px），不覆盖 `localStorage` 偏好；其他路由外层布局完全不变。
- [ ] **AC2（顶栏零溢出）**：顶栏取消固定 `280px` 搜索占位列，改为 36px 锚点 + 展开浮层；去掉顶栏冗余父目录段；分三档（≥1200 / 900–1199 / <900）渐进紧凑，所有宽度下核心入口可达且无横向溢出。
- [ ] **AC3（三栏分档与中栏保护）**：纯函数布局引擎准确实现 `wide`（≥1280 双栏 + ≥420px 中栏保护）、`medium`（960–1279 互斥单栏 + ≥420px 保护）、`compact`（<960 单栏全宽 + 左右浮层抽屉 + 遮罩/Esc 关闭 + 选文件自动收起左抽屉）。
- [ ] **AC4（控制台与细条）**：只读横幅、`actionPending` 条、控制台顶栏、`ConsolePanel` 头与空态在窄宽/矮高下无溢出、无裁切。
- [ ] **AC5（水合与兼容）**：首帧无水合不一致；保留既有 `buildStudioGridTemplateColumns` / `buildStudioGridTemplateRows` 导出行为与全部 E2E 选择器。
- [ ] **AC6（测试与门禁）**：新增纯函数单测覆盖全部断点、动态夹紧、互斥与抽屉切换；`cd frontend && pnpm exec tsc --noEmit`、`cd frontend && pnpm exec vitest run components/common/sync/__tests__/ lib/i18n/__tests__/translation-coverage.test.ts` 全绿。
