# 工作台未保存草稿：防抖自动保存 + 离开拦截

> 来源：GitHub #113。与 #112（侧栏收起）并行，不互相阻塞。

## 背景

工作台 `/workbench` → `DataSyncStudio` 编辑后未点「保存草稿」时，脏数据只在内存 `editorDrafts`，刷新/离开会丢；无 `beforeunload` / 站内离开确认；无自动保存。

拍板：**两者都要**——以防抖自动保存草稿为主；若仍有未落盘内容，离开时再拦截。

## 目标

减少忘记手动保存导致的草稿丢失；保持「保存草稿 ≠ 发布新版本」。

## 范围

- `DataSyncStudio` 及相关保存 / 离开链路（前端）
- 自动保存只走现有保存草稿能力（`persistCurrentFile(false)` / `updateTask`）
- 站内离开拦截 + 浏览器刷新/关页提示
- 顶栏共享保存状态（保存中 / 已保存 / 保存失败）

## 非范围

- 不改变「发布新版本」语义与门禁（禁止自动 `publishTask`）
- 不做跨设备实时协同
- 不改 Console / 侧栏收起（#110 / #112）

## 验收标准

1. **AC1** 可编辑任务下，正文/相关草稿字段变更后 1–2s 防抖自动保存草稿；成功清 dirty；失败保留 dirty + 可见错误，可重试。
2. **AC2** 顶栏可见状态：保存中 / 已保存 / 保存失败（中英可切换）；手动与自动共用，不双重打扰。
3. **AC3** 自动保存永不触发发布；发布/运行门禁不变。
4. **AC4** dirty 或自动保存进行中/失败未恢复时，离开工作台出现确认：留下 / 保存并离开 / 丢弃并离开；默认焦点不在「丢弃」。
5. **AC5** 同上风险时挂 `beforeunload`；无风险时不挂。
6. **AC6** `!editor.canEdit`：不自动保存、不误拦。
7. **AC7** 自动保存成功后树/页签脏标记与 `editorDrafts.dirty` 一致；多页签未落盘草稿保留至保存成功或明确丢弃。
8. **AC8** 符合前端 UI 约定（高信噪比、弹窗规范）。
