# 二次开发

面向开发者的 STX 扩展说明。产品介绍与用户安装见 [README.md](../README.md) / [README_CN.md](../README_CN.md)。

更完整的英文版（含 Windows 细节）见 [secondary-development.md](./secondary-development.md)。

## 技术栈

- 后端：Go 1.26.10、Gin、GORM、OpenTelemetry、Swagger
- 前端：Next.js 15、React 19、TypeScript、Tailwind CSS、Shadcn UI
- Agent：部署在目标主机的 Go 进程，经 gRPC 与控制面通信
- 数据库：SQLite（默认）/ MySQL / PostgreSQL

## 本地开发

```bash
cp config.example.yaml config.yaml
go mod tidy
go run main.go api

cd frontend
pnpm install
pnpm dev
```

默认界面：`http://localhost:3000`  
默认账号：`admin` / `admin123`

```bash
go test ./...
cd frontend && pnpm test
```

## Protobuf / gRPC 代码生成

修改 `.proto` 后需要重新生成：

```bash
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest

protoc --proto_path=. \
  --go_out=. --go_opt=paths=source_relative \
  --go-grpc_out=. --go-grpc_opt=paths=source_relative \
  internal/proto/agent/agent.proto

cp internal/proto/agent/agent.pb.go agent/agent.pb.go
```

确认更新：

- `internal/proto/agent/agent.pb.go`
- `internal/proto/agent/agent_grpc.pb.go`

## Agent 交叉编译

```bash
cd agent
GOOS=linux GOARCH=amd64 go build -o stx-agent ./cmd
GOOS=linux GOARCH=arm64 go build -o stx-agent-arm64 ./cmd
cp stx-agent ../lib/agent/stx-agent-linux-amd64
cp stx-agent-arm64 ../lib/agent/stx-agent-linux-arm64
```


## 本地构建 Docker 镜像

镜像只消费 `install/package-release.sh` 打出的 `dist/releases/` 产物，Dockerfile 内不再编译。先打包再构建：

```bash
make docker-images            # 打包产物 + 构建当前架构三个镜像 + sha256 校验
make docker-smoke             # 复用已有 dist/releases/，重建镜像并对 all-in-one 跑 smoke
make docker-images DOCKER_PLATFORMS=linux/arm64 DOCKER_IMAGES=all-in-one
```

详见 [打包发布说明 5.3](./打包发布说明.md#53-本地构建镜像先打包再构建)。
