# 诊断中心巡检面板改为列表与详情分栏（第 3 步 / 共 3 步）

## 背景

第 1 步（#171）外壳与巡检策略、第 2 步（#173）错误面板已对齐告警中心的列表 + 常驻详情栏。本步处理「巡检」面板（`DiagnosticsInspectionCenter.tsx`，1496 行）。独立的巡检报告页 `/diagnostics/inspections/:id`（`InspectionDetailPage.tsx`）与共享的 `InspectionEvidenceView.tsx` 不改。

## 已确认问题（代码证据）

1. **交互不一致**：详情是侧滑 `Sheet`；三个附属弹窗（发起巡检、生成诊断包确认、执行日志）用的是 shadcn `Dialog`，不是 Arc。
2. **状态计数只算当前页**：状态胶囊里「失败 / 已完成 / 运行中 / 排队」按当前 20 条统计，「全部」却是服务端总数（状态筛选本身走服务端，计数自相矛盾）。
3. **运行中的报告不会自动刷新**：发起巡检后列表停在 running / pending，必须手动刷新。
4. **无请求竞态保护**：`loadReports` / `loadDetail` 快速切筛选或切行时，旧请求晚到会覆盖新结果（错误面板有 requestId 保护，这里没有）。
5. **未选集群时「发起巡检」可点，点完才 toast 提示**；规范要求禁用并在 Tooltip 说明原因。
6. **硬编码中文**：`重置筛选`、列头 `编号 / 触发方式 / 发现项与摘要概览 / 回溯窗口 / 完成时间`、`{n} 严重 / 警告 / 提示`、`摘要`、`完整报告`、`分钟`、回溯预设 `15分钟 … 24小时`。

## 需求

- R1 新巡检面板（替换 `DiagnosticsInspectionCenter`，props 同旧：`clusterId`、`reportId`、`onSelectReport`，另加 `clusterOptions`）：
  - 工具栏：状态分段（全部 / 失败 / 已完成 / 运行中 / 排队，服务端筛选，**不显示分桶计数**）+ 严重度 Arc `Select` + 重置筛选（有筛选时出现）+ 发起巡检（未选集群时禁用，Tooltip 给出 `selectClusterFirst` 原因）+ 刷新。筛选变化回第 1 页。
  - 列表：`TableCard`（骨架 / 错误重试 / 空态 / 服务端分页 20 条）；行 = 编号、触发方式、状态软徽章、发现项计数徽章（严重 / 警告 / 提示）+ 摘要、回溯窗口、完成时间；行可点击、方向键 / Enter 可达。删掉行内「摘要」「完整报告」按钮（完整报告入口放详情底部）。
  - 详情：`DetailHost` 宽栏（窄屏抽屉），J/K 当前页切换；内容沿用旧 Sheet 的信息（元信息、发现项卡片按严重度排序、零发现 / 未完成状态说明、诊断包区：生成 / 重新生成 / 执行日志 / 预览报告 / 下载），底部 = 查看完整报告、关闭。所属集群按报告 `cluster_id` 解析名称。
  - 发起巡检、诊断包确认、执行日志三个弹窗改 Arc `Dialog`（`.arc-compact`），表单字段与校验逻辑原样保留；回溯预设与单位走 i18n。
  - 自动刷新：当前页存在 `pending` / `running` 报告时每 5 秒静默刷新列表（不显示骨架、不打断选择），打开的详情若是运行中也同步刷新；无运行项或卸载时停止。
  - 请求竞态：列表与详情都加 requestId 保护（同错误面板）。
  - URL `report_id` 同步 / 深链打开保持；发起巡检成功后自动打开新报告（保持旧行为）；诊断包轮询保持。
- R2 i18n 中英同步；删除不再使用的键（grep 确认，`InspectionDetailPage` 仍在用的保留）。
- R3 测试：vitest（筛选参数与回第 1 页、运行中自动刷新用假定时器、竞态丢弃旧响应、未选集群禁用发起）；E2E mock 模板（列表、状态筛选、打开详情 + J/K、发起巡检成功并打开新报告、发起失败时弹窗保留并提示）。

## 验收标准

- [ ] 状态分段不再显示与总数矛盾的计数；筛选走服务端。
- [ ] 运行中报告无需手动刷新即可变为完成。
- [ ] 未选集群时「发起巡检」禁用且有原因提示。
- [ ] 新面板无硬编码中文可见文案。
- [ ] tsc / vitest / eslint / translation-coverage / 三个诊断 E2E（errors、policies、inspections）通过。

- 后端接口（无改动）。
- `DetailHost` 等提升到 `common/layout`：告警中心的并行改动已落地，之后单独一个小 PR 做。
