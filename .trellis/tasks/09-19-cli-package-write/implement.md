# 安装包管理 CLI 写操作覆盖实施计划

## 1. 任务启动前检查

- [ ] 读取 backend、CLI、执行安全、错误处理、质量和 shared guides 规范。
- [ ] 检查当前分支和无关未提交文件，限定本任务改动范围。
- [ ] 确认本地 STX 服务、软连接、登录配置和 Agent 状态。
- [ ] 检查安装包服务的上传校验、分片状态、下载 goroutine、取消信号和错误映射。

## 2. 客户端与命令实现

- [ ] 增加流式 multipart 客户端方法和定向测试。
- [ ] 增加统一写操作选项、确认 Header、幂等键和警告输出。
- [ ] 登记版本刷新和主机安装命令查询，或接入已有登记项。
- [ ] 实现 package 上传和分片上传命令。
- [ ] 实现 package 下载、取消和删除命令。
- [ ] 保证 package 根命令只注册一次，并补充帮助、样例和输出样例。

## 3. 服务端保护和取消修正

- [ ] 为本批写接口接入最小服务端确认和幂等校验。
- [ ] 修正下载取消，使取消信号真实传递到下载执行过程。
- [ ] 补充取消后的临时文件清理和状态不倒退测试。
- [ ] 补充直接 API 调用未确认、幂等重复和幂等冲突测试。

## 4. 质量检查

- [ ] `gofmt` 修改过的 Go 文件。
- [ ] 运行 CLI、client、installer、execution 定向测试。
- [ ] 运行 `go test ./...`。
- [ ] 运行 `go vet ./...`。
- [ ] 运行操作登记合约报告并检查路由覆盖变化。
- [ ] 对本任务文件运行 `git diff --check`，不检查或修改无关安装发布文件。

## 5. 本地真实验证

- [ ] 构建 `dist/stx`，确认 `/Users/mac/.local/bin/stx` 仍指向它。
- [ ] 重启本地服务并确认 capability 包含本批操作。
- [ ] 用隔离配置登录本地服务。
- [ ] 刷新版本并调用主机安装命令查询。
- [ ] 使用测试版本完成单文件上传、查询和删除。
- [ ] 使用测试版本完成分片上传、查询和删除。
- [ ] 启动下载并在可控时间内取消，检查任务状态和临时文件。
- [ ] 验证确认缺失、`--confirm`、幂等重试、幂等冲突、JSON/table/raw/`--pick` 和稳定退出码。

## 6. 提交与归档

- [ ] 使用 `trellis-check` 完成最终检查。
- [ ] 如发现长期适用的新 CLI 规则，更新对应 spec；否则不修改规范文件。
- [ ] 只暂存本任务相关文件并使用中文提交信息。
- [ ] 记录真实验证结果和未覆盖项。
- [ ] 归档本任务并记录开发日志。
