# 列表与常驻详情栏联动动效（克制版）

## 背景

告警中心、诊断中心的 7 个列表都用 `DetailHost` 做"列表 + 常驻详情栏"：
主区域 ≥1080px 时详情是右侧常驻栏，窄屏退化为抽屉。现在点开一行时：

- 选中行只换一层浅色底（`list-detail.module.css` 的 `.rowActive`）；
- 详情栏直接出现、关闭时直接消失（`DetailHost.tsx` 里 `if (!open) return null`）；
- 列表和详情栏之间固定 16px 间距，两张卡片各自有边框，看不出"这份详情属于哪一行"。

参考用户提供的 keshav（@kshvbgde）抽屉动效截图（"drawers if they were not boring"），
2026-11-21 用户确认采用**克制版**：靠层次而不是边框把选中行和详情栏连成一体，其余部分只变淡、不模糊。
原型见 `research/prototype.html`（浏览器直接打开，可切浅色 / 深色，点行、J/K、Esc 都可交互）。

## 范围

使用 `DetailHost` 且有行选中态的 7 个列表：

| 列表 | 文件 |
|---|---|
| 告警 | `monitoring/alerts/AlertsPanel.tsx` |
| 告警规则 | `monitoring/rules/RulesPanel.tsx` |
| 作业规则 | `monitoring/rules/JobRulesPanel.tsx` |
| 通知渠道 | `monitoring/notify/NotifyPanel.tsx` |
| 诊断策略 | `diagnostics/policies/PoliciesPanel.tsx` |
| 错误中心 | `diagnostics/errors/ErrorsPanel.tsx` |
| 巡检 | `diagnostics/inspections/InspectionsPanel.tsx` |

PR #163 合入后，主机列表也会接入 `DetailHost`，按同一套接入（见 design §6）。

## 需求

- **R1 层次**（≥1080px，详情栏打开时）：
  - 列表和详情栏之间的间距收为 0；
  - 列表退到底层：外框和行分隔线去掉，底色压暗一档；
  - 选中行和详情栏在上层：白底加阴影，详情栏不画边框，选中行右端直接接到详情栏；
  - 选中行上方、下方的列表各成一段，贴着选中行的一侧是圆角；
  - 选中行右端上下各有一个 10px 的凹圆角，平滑接进详情栏左边缘。
- **R2 退后**（克制版，不模糊）：
  - 其余行按离选中行的距离逐级变淡：每隔一行降 10%，最多降到 50%，不加模糊；
  - 面板工具栏（列表上方的搜索、筛选）降到 70% 不透明度，鼠标悬停或焦点进入时立即恢复；
  - 鼠标移到变淡的行上，这一行立即恢复。
- **R3 开合与切换**：
  - 打开：详情栏宽度展开、从右侧滑入淡入，栏内各分区依次淡入上移；
  - 切换到另一行：分区更快地重新淡入，选中行和两段列表的圆角随之移动；
  - 关闭：详情栏收起淡出，**动画播完后再卸载**；列表恢复原来的带框卡片和 16px 间距。
- **R4 名称飞入**：
  - 点击某行或在行上按回车打开 / 切换时，这一行的名称从列表飞到详情栏头部显示名称的位置，落地后换成真实文字；
  - 用 J/K、头部 ↑↓ 按钮切换、URL 深链恢复时不飞，只换内容；
  - 每个列表飞的字段和落点见 design §4；源文字和落点文字不一致的列表不飞（巡检）。
- **R5 降级**：
  - 窄屏（<1080px，抽屉形态）不做 R1、R2、R4，保持现状；
  - 系统开启"减少动态效果"时，只保留不透明度变化，不位移、不飞入；
  - 当前页没有选中行时（例如翻页后），列表不拆段、不变淡，详情栏照常显示。

## 验收标准

- [ ] 7 个列表在 ≥1080px 下打开详情，视觉与 `research/prototype.html` 一致：零间距、选中行与详情栏相接处无线、上下两段列表圆角、接口凹圆角。
- [ ] 其余行按距离变淡、无模糊；工具栏变淡且悬停或聚焦时恢复。
- [ ] 关闭时详情栏有退出动画，结束后从 DOM 卸载；关闭后列表外观与改动前一致（截图对比）。
- [ ] 点击 / 回车打开时名称飞入且落点准确；J/K、↑↓、深链不飞；连续快速点击不残留飞行中的副本。
- [ ] 第一行、最后一行、单行列表、翻页后选中行不在本页、轮询刷新这几种情况外观正确。
- [ ] 窄屏抽屉、"减少动态效果"两种情况按 R5 降级。
- [ ] 浅色、深色都正确。
- [ ] tsc、vitest、eslint 通过；现有诊断与告警 E2E 通过；PR 附 Egolite 录屏，覆盖 7 个列表的打开、J/K、关闭。

## 不在范围

- 原版的模糊景深效果（只做克制版）。
- 飞入第二个字段（例如状态）：详情栏头部没有统一的状态位置，需要先给 `DetailHost` 加插槽，以后再议。
- 窄屏抽屉的动效、`DeliveriesPanel` 等没有详情栏的列表、详情栏内部内容的改版。
