# Type and layout

## 007 Type switches (rule)

- Also called: 中英文排版的CSS设置, 中英文排版
- Applies: Text-heavy web pages: sites, blogs, landing pages, docs, any mixed Chinese and English text.
- Signals: No text-wrap: balance or pretty; numbers in tables or counters without tabular-nums; no lang on <html>; Chinese paragraphs without justify or line-break rules.
- Skip: Native apps (the rules are CSS).
- Demo: https://vibedesign.tips/007-type-switches/
- Text: tips/007-type-switches.md (4.6k characters)

## 008 Wiki layout (rule)

- Also called: 兼顾PC和移动端的Wiki布局, Wiki 布局, 帮助中心布局
- Applies: Docs, wikis and help centers on desktop and mobile.
- Signals: A docs layout with a sidebar and a table of contents; Docusaurus, VitePress, Nextra, Mintlify, Starlight; a sidebar that scrolls away with the page.
- Skip: Products without a docs or help section.
- Demo: https://vibedesign.tips/008-wiki-layout/
