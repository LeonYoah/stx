## 使用条件

- [ ] 功能涉及 3 层以上（API、Service、组件、数据库）
- [ ] 数据在层与层之间格式发生变化
- [ ] 多处消费者需要同一份数据
- [ ] 不确定某段逻辑该放在哪一层

→ 阅读 [跨层思考指南](./cross-layer-thinking-guide.md)

---

## 修改前检查

修改公共值、路径、配置键或协议字段前，先搜索所有生产者、消费者、测试和生成脚本：

```bash
rg -n "要修改的值" .
```
