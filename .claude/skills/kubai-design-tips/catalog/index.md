# Catalog

Read the categories that match the product, then the tips they list.
Kinds: a rule is a judgment most products need, so check it in every review; an effect is a look people choose, so suggest it only where the product has a place for it or when the user asks.

- catalog/feedback.md (Feedback and states). rules: 009 Overlays, 016 Toast or notification, 017 Loading states.
- catalog/motion.md (Motion and transitions). rules: 005 Drag to reorder, 011 Easing curves, 015 UI continuity; effects: 006 Book cards, 014 Card delete, 019 Scroll cards.
- catalog/components.md (Components and surfaces). rules: 002 Cascade menu, 004 Continuous corners, 020 Choice controls; effects: 001 Skeuomorphic buttons, 010 Liquid glass, 012 Message bubbles.
- catalog/type-layout.md (Type and layout). rules: 007 Type switches, 008 Wiki layout.
- catalog/effects.md (Visual effects). effects: 003 ASCII and dither, 013 Shockwave glow, 018 Holo card.
