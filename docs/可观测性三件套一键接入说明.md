# STX 可观测性三件套说明

## 设计原则

- 本地 Prometheus / Alertmanager / Grafana **只通过** `$INSTALL_DIR/bin/{start,stop,status}.sh` 管理。
- 默认 `--observability auto`：有本地栈且 `config.yaml` 中 `observability.enabled` 不为 `false` 时启动；否则跳过。
- 远程已有三件套：只改 `config.yaml`，不要装本地 observability 包。

## 配置单源

模板在仓库 `install/observability/`（`*.tpl` + rules/dashboards）。

```bash
# 裸机安装目录（install 时会自动调用）
./install/observability/render.sh bare /opt/stx/observability

# Docker Compose 目录
./install/observability/render.sh docker deploy/docker/observability
```

`deploy/docker/observability/` 为生成物；`package-release` 打包 Docker 前会重新渲染。


```bash
/opt/stx/bin/start.sh                 # 默认 auto
/opt/stx/bin/start.sh --observability off
/opt/stx/bin/start.sh --observability on
/opt/stx/bin/stop.sh
/opt/stx/bin/status.sh
```

资产目录：`/opt/stx/observability/{prometheus,alertmanager,grafana}`。  
安装时若启用 observability，会写入默认配置与 `observability.enabled: true`。

| 服务 | 默认地址 |
| --- | --- |
| Grafana | http://127.0.0.1:3000 |
| Prometheus | http://127.0.0.1:9090 |
| Alertmanager | http://127.0.0.1:9093 |

## 外部 / 远程三件套

1. 配置 STX：

```yaml
observability:
  enabled: true
  prometheus:
    url: "http://prom.example:9090"
  alertmanager:
    url: "http://am.example:9093"
  grafana:
    url: "http://gf.example:3000"
```

2. 按接入规范在外部栈配置 HTTP SD / webhook / datasource（本仓库不自动改远程配置）。

3. 本机不要落盘 observability 包，或 `start.sh --observability off`。

## 检查清单

- STX 健康：`GET /api/v1/health`
- HTTP SD：`GET /api/v1/monitoring/prometheus/discovery`
- Webhook：`POST /api/v1/monitoring/alertmanager/webhook`
