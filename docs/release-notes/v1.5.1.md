# v1.5.1 发布说明 / v1.5.1 Release Notes

## 升级须知 / Upgrade Notes

- 建议升级前备份数据目录（SQLite 复制 `data/stx.db*`，MySQL 用 mysqldump）。
  Back up the data dir before upgrading (copy `data/stx.db*` for SQLite, mysqldump for MySQL).
- 后端报错与进度文案改为按请求语言单语返回：前端会自动带上界面语言的 `Accept-Language`，
  API 调用方也可用 `?lang=` / `?language=` / `?locale=` 或 `Accept-Language` 指定 `zh` / `en`；
  不再返回中英拼接的双语句子。Backend error and progress messages are now returned in a
  single language resolved per request: the frontend sends the UI language via
  `Accept-Language`, and API callers may use `?lang=` / `?language=` / `?locale=` or the
  `Accept-Language` header for `zh` / `en`; bilingual Chinese+English concatenated messages
  are no longer produced.

## 破坏性变更 / Breaking Changes

- 同步任务共享权限升级为三态 `access_level`（私有 / 只读共享 / 可编辑共享），旧的两态
  读写语义被取代；已有任务的共享设置按新模型迁移，API 与 `stx` CLI 同步对齐。
  Sync-job sharing upgraded to a three-state `access_level` model (private / shared
  read-only / shared editable), replacing the old two-state semantics; existing shares
  migrate to the new model, with API and `stx` CLI aligned.

## 新功能 / Features

- 全链路国际化治理：统一语言协商链路（`Accept-Language` + `?lang=` 解析 + locale 中间件），
  后端 1100+ 处中英拼接文案清零，前端兜底错误本地化，CI 硬门禁拦截新增双语拼接。
  End-to-end i18n governance: unified language negotiation (`Accept-Language` +
  `?lang=` parsing + locale middleware), 1100+ bilingual-concatenated backend strings
  migrated to single-locale output, frontend fallback errors localized, and a CI gate
  blocks new bilingual literals.
- 同步作业指标页签改版：快照分段条 + 趋势桑基图。Redesigned sync job metrics tab:
  snapshot segment bar + trend Sankey diagram.
- 作业列表行数据瘦身：列表接口返回精简字段，详情由前端共享 hook 自持，降低列表开销。
  Slimmer job-list rows: list API returns trimmed fields and full details are held by
  a shared frontend hook, cutting list payload cost.
- 工作台外壳响应式重构：全视口外壳、顶栏三档收拢、三栏自适应与窄宽抽屉。
  Workbench shell responsive rework: full-viewport shell, three-tier top bar, adaptive
  columns and narrow-width drawer.

## 修复 / Fixes

- 自升级在识别不到前端进程时也正确替换前端文件，升级 e2e 补充断言。
  Self-upgrade now replaces frontend files even when no frontend process is detected;
  upgrade e2e assertions added.
- 同步推送调度时在 schedule 上对称携带 `environmentCode`。Schedule push now carries
  `environmentCode` symmetrically.
- 对账与实时代理端点协议合并、任务定义覆盖与单轮缓存统一。
  Reconcile and realtime-proxy endpoint protocol merge, task definition override and
  single-round cache unified.
- 集群端点优先按集群动态解析，引擎客户端独立短建连超时。
  Cluster endpoints resolve dynamically per cluster; engine client gets its own short
  connect timeout.
- sparkline 点位按 jobId 归属，切换作业不再显示上一作业曲线；`useJobDetail` 丢弃乱序
  返回的旧 `getJob` 响应。Sparkline points are attributed by jobId so switching jobs no
  longer shows the previous curve; `useJobDetail` drops stale out-of-order `getJob` responses.
- 较新摘要的白名单键集合视为权威，缺失键即已清除。Newer summaries treat the whitelist
  key set as authoritative — absent keys count as cleared.
